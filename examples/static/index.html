Print it once.

VITRINE runs Paper Shaders over the product image your page already renders and prints it once. The photo stays underneath, as the content.

Move over the print: the loupe shows the photo. Click to lift the whole print. Tap the print: the loupe moves there.

Three lines, three stacks

the <img> stays the content · the print is a layer

01 · Liquid (Online Store 2.0)

{% render 'vitrine-card-media',
  image: card_product.featured_media,
  sizes: '(min-width: 990px) 25vw, 50vw' %}

{{ 'vitrine.js' | asset_url }}   ← one module, 46 KB gzip
sections/vitrine-hero.liquid     ← colour pickers + sliders
sections/vitrine-editorial.liquid

Copy the folder, paste one settings group, wrap the card image. Merchants tune everything in the theme editor.

02 · React 19 / Next.js

import { ProductMediaShader }
  from 'vitrine-shaders/react';

<ProductMediaShader image={product.featuredImage}>
  <Image … />
</ProductMediaShader>

Server HTML is a plain image. The element arrives after hydration, 860 B of wrapper.

03 · Plain HTML

<script type="module"
  src="vitrine.js"></script>

<vitrine-shader effect="dither"
  preset="newsprint" reveal="hover">
  <img src alt width height>
</vitrine-shader>

No bundler. No WebGL2, no CORS? The photo stays and nothing is logged.

PC-008 · Halftone Collage · 2026

EL
FUNKADOR

Nº 01 of the NIWWTS Lucha Federation. An anonymous strongman, photographed in 1905, drafted seventy years later into a fight he never agreed to. The mask was baked into the print before the halftone pass - he has always been wearing it. Three of him dive across a scrolling wall of type because the main event never books just one. Tap the floor and somebody takes the bump.

Built on Paper Shaders · Apache-2.0

Made with Paper.

The four effects are image-dithering, halftone-cmyk, mesh-gradient and paper-texture from @paper-design/shaders 0.0.82, pinned. The page layout was designed on the Paper canvas before it was coded; the proof print at the top came later, in code. The presets started as frames in Paper and were picked on renders of the element; they live in presets/*.json, the same files Liquid and React use. Pixel-compatibility tests against shaders-react: 0 different pixels.
